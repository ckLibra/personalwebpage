# Shuang Sun — academic homepage

A standalone, responsive academic homepage in white, lavender and blue.

Open `index.html` for a local preview. No package installation or build is required.

## Hosting and privacy

Keep the GitHub source repository **private**. The user has authorized the website itself to be publicly accessible. Do not commit the source résumé PDF, phone number, birth date, or other personal identifiers.

GitHub Pages hosting from a private personal repository requires an eligible GitHub plan. If that is unavailable, use a public static hosting provider connected to this private repository. Never change repository visibility to work around hosting restrictions.

## Content

- Education lists only the Tsinghua Ph.D. (graduation confirmed by the site owner).
- Selected publications use titles from the supplied résumé and verified publisher links.
- The résumé's incomplete 2020 paper and incomplete additional-publication entries are omitted rather than reconstructed.
- The portrait was extracted from the supplied résumé; the original PDF is not distributed.
- The animated instrument illustration is conceptual, not a published scientific result.
- No analytics or third-party scripts are loaded.

Edit `index.html`, `assets/site.css` and `assets/site.js` to update content, style and animation.
